# Portfolio — Project Instructions

## Design decisions

All design, copy, layout, and UX decisions in this project must follow
`DESIGN-PRINCIPLES.md` (Perception-First Design + Design with Intent).

In practice:

- Before proposing or making a design change, analyze it against the five PFD
  layers (L0 cognitive load → L1 first impression → L2 processing fluency →
  L3 perception bias → L4 decision architecture). Fix lower layers first.
- The `pfd` skill is installed — invoke it for any design, copywriting, or
  communication work in this repo.
- Every design decision needs a stated reason grounded in cognitive science or
  evidence — never aesthetics alone.
- Accessibility and user autonomy are non-negotiable: no dark patterns,
  keyboard-navigable, screen-reader viable, sufficient contrast.
